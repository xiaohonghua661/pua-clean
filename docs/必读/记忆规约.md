# #MEM — 记忆规约

## 做什么

**记忆必须有，且只存当前工作区。** 本会话学到的跨会话事实，收尾前必须落进 `<工作区>/.collab/`；只留在对话里 = 制造 lock-in，违约。

**工作区之外一律不算落盘**——写进 home 下任何位置（各 CLI 的记忆池、dd 安装目录）都不满足「跟仓库走 / 走查可见 / 跨 AI 可见 / 工作区改名不失联」，等于没存。

## 落点：**当前工作区 `.collab/`**，唯一

记忆存**工作区内**，不存任何 home 目录下的位置。落点只有一个，不用逐次判断：

形态**照抄各 CLI 官方 memory 目录**（`memory/` + `MEMORY.md` 索引 + 一事一文件 + frontmatter），只是搬进工作区并按 AI 分区：

```
<工作区>/.collab/
├── memory/                     # 跨 AI 共享记忆
│   ├── MEMORY.md               #   本目录索引
│   └── <topic>.md              #   一事一文件
├── claude/memory/              # 只对 Claude 成立的事实（自带 MEMORY.md）
└── codex/memory/               # 只对 Codex 成立的事实（自带 MEMORY.md）
```

- **位置即适用范围**：换个 AI 还成立吗？成立 → `memory/`；不成立 → `<该AI>/memory/`。不用文本标记。
- `<AI>/` 是那家 AI 在本工作区的整个命名空间，`memory/` 只是其中一类——将来放 `handoffs/` 等不必搬家。加新 AI 就加同名目录，零命名约定。
- 工作区已有的协作台账（`LESSONS.md` / `DECISIONS.md` / `TASKS.md` 等）是流水，不是事实库，**不动、不并入**。

### 文件格式（照抄官方，不自创）

**`MEMORY.md`**：纯指针清单，无标题无前言，一行一条 `- [标题](相对路径) — 一句话钩子`。冷启动只读它，需要哪条再按路径取——**正文不进索引，索引不存内容**。每个 `memory/` 各自维护一份。

**记忆文件**：kebab-case 文件名 = frontmatter 的 `name`；

```markdown
---
name: <kebab-case-slug>
description: <一句话：这条讲什么 + 何时用得上>
metadata:
  node_type: memory
  type: reference | project | user | feedback
  modified: <YYYY-MM-DD>
---

<自足的事实陈述>

**How to apply:** <下次该怎么用这条>。相关：[[其它记忆的 name]]。
```

**一事一文件**，按主题不按会话或日期；同主题追加进同一篇。
- 工作区根的 `CLAUDE.md`（Claude 自动读）与 `AGENTS.md`（Codex 自动读）各留一行指向 `.collab/`——这是自动加载的唯一依赖。
- `.collab/` 入不入库由该项目决定：团队共享就提交，含本机私密就 gitignore。

为什么不用各 CLI 的官方记忆池：`~/.claude/projects/<工作区编码>/memory/` 物理在 home、只是按工作区分键——**不跟仓库走、走查不可见、跨 AI 不可见、工作区改名即失联**；Codex 更没有对等的可写池（其 `memories_*.sqlite` 是按会话线程的自动摘要）。工作区 `.collab/` 是唯一四项全满足的位置。

**唯一例外**：对所有项目都成立的通用机制规约 → dd 公开层 `<INSTALL_DIR>/tags/`，走 #DD 管线 + #GIT 闸门，先问。

**瞬态不落盘**：多 agent 当下状态走 `dd note`；单人本轮判断走当前 CLI 的 plan / task primitive。

判不准跨不跨会话时按"跨"处理——漏写才是不可逆损失。**没有"路径未定所以不写"这条路**：`.collab/` 不存在就建。

## 不碰 home 下的记忆池（底线，不受三态开关影响）

禁止生成、更新或删除 `~/.claude/projects/**/memory/**` 下任何 `.md`，以及用户根或项目根 `CLAUDE.md` 的 memory 段。已有条目只读：仍成立 → 建议转 `.collab/`，转完由用户手动清理；已失效 → 指出失效点等用户处理。删除不可逆，那是用户本机资产。

## 搬工作区前的检查表

用户要把工作区搬到另一台机器 / 另一个路径时，先跑一遍这张表。**「记忆落工作区」这条规矩的全部意义就在这一刻兑现**——没兑现的部分现在不捞，搬完就再也捞不回来了。

| 档 | 位置 | 搬工作区时 | 处置 |
|---|---|---|---|
| **A** | 工作区内：代码、`docs/必读/`、`AGENTS.md`/`CLAUDE.md`、**`.collab/`** | ✅ 跟着走 | 不用管 |
| **A′** | 工作区内的 `temp/` | ⚠️ 看怎么搬 | **整目录拷贝**（复制、打包、rsync）时跟着走；**走 git clone 时只有那份 `.gitignore` 跟着走、内容一件不剩**（它自己的 `*` 把内容全忽略了）。里面本来就该只有中间物，丢了不心疼；真有要留的，说明它不该在 `temp/` |
| **B** | 宿主 CLI 在 `%TEMP%` / `/tmp` 下的 scratchpad | ❌ 带不走 | **不用捞**——按设计就是中间物。该留的本来就该落工作区 `temp/`（见 #SETUP） |
| **C** | home 下按工作区分键：`~/.claude/projects/<绝对路径编码>/memory/**`、同目录会话 `*.jsonl` | ❌ 带不走 | **搬之前必须捞**，见下 |

C 档为什么最危险：**键是工作区绝对路径的编码**（`D:\proj\demo` → `D--proj-demo`）。所以它不只是"新机器上没有"——**同一台机器把工作区换个路径，这些记忆一样对不上号**，而人只会以为是没同步。

搬之前三步：

1. **查有没有**：`ls ~/.claude/projects/<本工作区路径编码>/memory/`。有内容就是 C 档欠账。
2. **念给用户听，逐条问留不留**——不要整个目录照搬。那里躺的多半是早期没有 `.collab/` 时留下的，其中一部分早已失效；照搬等于把过期结论搬进新机器。
3. **留的转成 `.collab/` 的形态**（一事一文件 + frontmatter + 索引一行），转完**告诉用户原件在哪**、由用户自己删——上一节的底线不变，不删 home 下的东西。

工作区**没有** `.collab/` 时（早期版本建的工作区就没有），先按 #SETUP 把落点建起来再转。顺带核一眼 `AGENTS.md` 与 `CLAUDE.md` 是不是两份都在——缺哪份，哪家 CLI 到了新机器照样读不到规约。

## 流程

1. **判类型**：跨会话？→ 落盘；否则瞬态，不落。
2. **判位置**：只对某 AI 成立 → `.collab/<该AI>/memory/<topic>.md`；跨 AI → `.collab/memory/<topic>.md`。同主题已有文件就追加进去，不新开。
3. **写**：**先重读该文件**（别的 agent 可能刚改过）→ 只用 `Edit` 追加或改某一节，**禁止整篇 `Write` 覆盖**（Edit 的匹配失败会报错，天然挡住互相抹掉；整篇写会静默丢别人的内容）。
4. **更新索引**：新增 / 删除 / 改名文件时，同步**该目录** `MEMORY.md` 的对应行；只是往已有文件追加内容则不动索引（除非钩子已描述不准）。
5. **告知**：报路径 + 判定理由。
6. **收尾自检（闸门）**：声明完成前逐条过"本会话产生的跨会话事实是否已落 `.collab/`"；未落的立即补写或列入 #CODE `missing`，不许静默带走。

**subagent 不自己写 doc**：把发现回报主线，由主线统一落盘（防碎片、防并发）。

**两个 AI 结论矛盾时**不开两份文件：同一节里并列记两边结论 + 各自证据 + 日期，标"未定"，由用户裁决后收敛成一条。

不要把口头规则原样写盘：它常含上下文，脱离上下文会变成错误 fact——先提炼成自足陈述再写。

## 三态开关

调节**本规约是否强制**与**单条便签续存**，都不打开写 memory 池的口子。

| 触发语 | 态 | 执行 |
|---|---|---|
| "禁用 #MEM" | 会话级停用 | 本会话不再按本规约主动落盘、不再拦截用户写盘请求；不改文件，新会话恢复。"启用 / 恢复 #MEM" 复原 |
| "全局禁用 #MEM" | 全局停用 | `DD_AGENT=<id> <INSTALL_DIR>/bin/dd.cmd announce "禁用 MEM"`；各 agent 下次 dd 调用收 📢 后各自停用。`announce --clear` 解除 |
| "#MEM 记住 XXXX" | 单条防压缩便签 | 复述内容 + 判定 → 写进本会话 scratchpad 便签 `.md` → 约定压缩后回读。便签是会话级瞬态，不跨会话；若实为长期 canonical fact，仍按上表落 doc，不用便签冒充长期存储 |

`announce` 非豁免命令，先 `dd id` 生成再带 `DD_AGENT=<id>`。

## 失败

| 现象 | 处置 |
|---|---|
| 会话结束时跨会话事实只在对话里，没落盘 | 违约。立即补写 `.collab/`，收尾报告标注补救 |
| 因"用户没指定路径"而不写 | 借口。落点固定是工作区 `.collab/`，不存在就建 |
| 记忆写进 home 下任何位置（`~/.claude/…`、`~/.codex/…`） | 违约。工作区外的一律不算数，移进工作区 `.collab/` |
| 整篇 `Write` 覆盖已有记忆文件 | 会静默抹掉别人的内容。只许 `Edit` 追加/改节 |
| 新增/删了记忆文件却没动 `MEMORY.md` | 索引漂移 = 后续 agent 找不到或找到不存在的。同一次改动里补上那行 |
| 把正文塞进 `MEMORY.md` | 主脑只放一行指针；正文回各自文件 |
| 收到"记住 X"便写 `feedback_*.md` | 改走 `.collab/` 或 `dd note` |
| 发现 stale fact 后直接改 home 记忆池 | 只告知 stale 点，由用户处理 |
| 把本会话临时判断写进 `.collab/` | 只存跨会话事实；临时判断走 `dd note` / plan primitive |
| 本机路径 / 账号写进 dd 公开层 tag | 公开层禁本机信息；这类内容属工作区 `.collab/`，公开层留占位符 |
| `announce` 报 `no_agent_id` | 先 `dd id` 生成再带 `DD_AGENT=<id>` |
| 更高优先级指令与本 doc 冲突 | 遵循更高优先级指令并显式报告冲突；不声称项目 doc 可覆盖 system / developer 指令 |
